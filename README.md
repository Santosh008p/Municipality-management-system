# Municipality Management System

A digital platform that enables citizens to access municipality services online, apply for official documents, report public issues, and track requests without visiting municipal offices.

---

# 🚀 Phase 1: MVP (Launch Version)

## Goal

Launch a fully functional citizen portal that digitizes the municipality's most frequently used services.

## 👤 Citizen Portal

- User Registration & Login
- Citizen Profile Management
- Dashboard
- Document Upload Management
- Application History
- Notification Center
